# MACE Web Application — UX Design Critique

## Anti-Patterns Verdict

**Start here.** Does this look AI-generated?

**LLM assessment**: MACE exhibits a moderate AI slop footprint. While its functional domain utility (maintenance tracking, breakdown logs, PDF report generator) is strong, the UI suffers from visual gimmicks including blue/red radial background glow halos (`.card-glow-*`), hover icon tilt rotations (`rotate(4deg)`), 4px left-border side-stripes on dark sidebar nav items, and low-contrast slate captions (`#94a3b8`, `#9b9b97`).

**Deterministic scan**: Code inspection uncovered 18+ accessibility violations (clickable `th`/`td`/`div` without keyboard event listeners or ARIA roles), 12+ WCAG AA color contrast failures (< 4.5:1 ratio), 120+ pervasive inline `style={{...}}` overrides, 40+ hardcoded pixel constraints/magic numbers, and a critical `ReferenceError: vosfItems is not defined` runtime crash bug on fallback routes in [`src/App.tsx:L183`](file:///d:/UserProfiles/Desktop/mace/src/App.tsx#L183).

**Visual overlays**: Browser injection fallback signal used (headless assessment in current session environment).

## Overall Impression
MACE is an ambitious, high-utility industrial engineering management portal. It shines with power-user accelerators (Shift+Click row range selection, Alt keys, A4 landscape PDF generator). However, its visual execution is bogged down by AI-scaffold tropes (halo glows, side-stripes, hover tilts), low-contrast captions, and high cognitive load across primary views.

## What's Working
1. **Power-User Accelerators**: Global keyboard shortcuts (`Ctrl+K` search, `Alt+H/T/P` page quick-jumps), Shift+Click table row multi-selection, and instant CSV data export/import.
2. **Resilient Data Sync Strategy**: Real-time Firebase subscriptions with local storage caching fallbacks (`mace_tasks_cache`, `mace_machine_classify_cache`) and a prominent sticky offline status indicator.
3. **Domain-Tailored Capabilities**: Plant-specific tools including the Machine Classify S/A/B/C criticality matrix calculator, breakdown duration analytics, and high-precision A4 landscape PDF report modal.

## Priority Issues

### [P0] Fix Runtime `ReferenceError` Crash on Default Route Fallback
- **Why it matters**: Navigating to an invalid or default fallback route crashes the application with `ReferenceError: vosfItems is not defined`.
- **Fix**: In [`src/App.tsx:L183`](file:///d:/UserProfiles/Desktop/mace/src/App.tsx#L183), change `vosfItems={vosfItems}` to `vosfItems={tasks}`.
- **Suggested command**: `$impeccable harden src/App.tsx`

### [P1] Eliminate Visual Anti-Patterns (Glow Halos, Side-Stripes, Hover Tilts)
- **Why it matters**: Radial gradient glows (`radial-gradient(...)`), 4px left side-stripes (`border-left`), and 4deg hover icon rotations add visual clutter and GPU overhead to an industrial dashboard.
- **Fix**: Remove `.card-glow-*` pseudo-elements, `rotate(4deg)` transforms, and `border-left` side-stripes in [`src/index.css`](file:///d:/UserProfiles/Desktop/mace/src/index.css). Replace with clean solid borders and subtle background fills.
- **Suggested command**: `$impeccable quieter src/index.css`

### [P1] Reduce Filter Bar Option Overload ($\le 4$ Rule Violation)
- **Why it matters**: [TroubleRecord.jsx](file:///d:/UserProfiles/Desktop/mace/src/pages/maintenance/TroubleRecord.jsx) and [MachineClassify.jsx](file:///d:/UserProfiles/Desktop/mace/src/pages/maintenance/MachineClassify.jsx) clutter top bars with 6–8 controls simultaneously, exceeding working memory limits and causing decision fatigue.
- **Fix**: Keep only 2–3 primary controls visible (e.g. Search input + New Entry button); collapse secondary status/shift filters into an expandable filter popover.
- **Suggested command**: `$impeccable layout src/pages/maintenance/TroubleRecord.jsx`

### [P1] Resolve Low Contrast & Accessibility (a11y) Violations
- **Why it matters**: Text colors like `#9b9b97` and `#94a3b8` fail WCAG AA 4.5:1 contrast standards. Interactive table headers and custom dropdown items lack keyboard focus and ARIA roles.
- **Fix**: Bump muted captions to `#64748b` (light bg) and `#cbd5e1` (dark bg). Add `role="button"`, `tabIndex={0}`, and `onKeyDown` listeners to clickable `th`/`td`/`div` elements in [`src/pages/maintenance/PMPlan.jsx`](file:///d:/UserProfiles/Desktop/mace/src/pages/maintenance/PMPlan.jsx) and [`src/pages/maintenance/TaskManagement.jsx`](file:///d:/UserProfiles/Desktop/mace/src/pages/maintenance/TaskManagement.jsx).
- **Suggested command**: `$impeccable audit src/`

### [P2] Add Dirty-State Guardrails for Inline Table Auto-Save
- **Why it matters**: [`TaskManagement.jsx`](file:///d:/UserProfiles/Desktop/mace/src/pages/maintenance/TaskManagement.jsx) commits cell changes to Firestore immediately on input `onBlur`, risking accidental data overwrite when tabbing through table cells.
- **Fix**: Render a visual dirty indicator (amber dot/border) on edited cells and confirm sync before committing.
- **Suggested command**: `$impeccable harden src/pages/maintenance/TaskManagement.jsx`
